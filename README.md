# 🎓 StudentTracker

**StudentTracker** — настольное приложение для учёта студентов, преподавателей и успеваемости. Позволяет работать с учебными данными через интерфейс Windows Forms, а информация хранится в базе данных SQL Server.

## Возможности

- Учёт студентов, преподавателей, групп и специальностей.
- Управление предметами, оценками и типами оценок.
- Просмотр среднего балла и поиск по данным.
- Авторизация, роли пользователей и смена пароля.
- Автоматическое создание базы данных и таблиц при первом запуске.

### Роли пользователей

| Роль | Возможности |
| --- | --- |
| **Администратор** | Управление учебными данными и пользователями |
| **Преподаватель** | Просмотр данных, добавление и удаление оценок |
| **Студент** | Просмотр оценок и среднего балла |

Разграничение доступных действий реализовано в интерфейсе приложения.

## Технологии

- **C#**, **Windows Forms**, **.NET Framework 4.8**
- **Microsoft SQL Server LocalDB**
- **ADO.NET** (`System.Data.SqlClient`)

## Запуск на Windows

Понадобятся **Visual Studio** с поддержкой разработки настольных .NET-приложений, **.NET Framework 4.8** и **SQL Server Express LocalDB**.

1. Склонируйте репозиторий:

   ```powershell
   git clone https://github.com/Denis-100/StudentTracker.git
   ```

2. Откройте в Visual Studio файл `StudentTracker/StudentTracker.csproj`.
3. Убедитесь, что доступен экземпляр LocalDB `(localdb)\MSSQLLocalDB`.
4. Запустите приложение (**F5**).

При запуске приложение создаёт базу **StudentsDB**, необходимые таблицы и первоначальную учётную запись администратора, если их ещё нет.

### Первый вход

- **Логин:** `admin`
- **Пароль:** `admin`

После первого входа смените пароль администратора. Эти данные предназначены только для локального учебного запуска.

## Структура проекта

- `Data/` — подключение к SQL Server, создание БД и операции с данными.
- `Forms/` — окна приложения и обработчики действий пользователя.
- `Services/` — запуск приложения, вспомогательные функции и работа с паролями.
